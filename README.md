# Japan Earthquake 3D Explorer

Static GitHub Pages prototype.

## Deploy
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.
4. Open the Pages URL.

The app loads `earthquakes.csv` and renders earthquake locations in 3D. This prototype uses a simplified coordinate/depth model; terrain and geological features are planned for later versions.
